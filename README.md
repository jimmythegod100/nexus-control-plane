# nexus-control-plane

NEXUS control plane - PostgreSQL + Redis + MCP discovery

## Overview

Foundation layer for the NEXUS AI agent orchestration framework. Provides PostgreSQL persistence, Redis caching, and MCP server discovery.

## Quick Start

```bash
git clone https://github.com/jimmythegod100/nexus-control-plane.git
cd nexus-control-plane
cp .env.example .env
make up
```
